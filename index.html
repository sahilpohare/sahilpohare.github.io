    GCP and AWS credits ran out, so I brought the workload home. A physical Kubernetes node in my kitchen started serving production traffic for real B2B customers on Skyfern AI and Pingerchips — about $8K a month in equivalent baseline cloud spend, avoided.

Transaction-critical work stays isolated on Vercel and serverless.

    Pingerchips — durable realtime for AI.

    The problem: AI work takes time. Change network, reload the page, or crash a worker, and a normal token stream dies — the agent starts over from zero.

    What I built: One realtime layer that replaces the usual duct tape of SSE, message history, job queues, and socket notifications. Built on Elixir/OTP and Rust NIFs. I founded it and run it.

    +--[ MIMIR ]---------- peer-to-peer compute + language models ----------+

    Open-source projects I built at 17 — the P2P work that led into MoltMesh

    Mimir — compute and models, peer to peer.

    What I built: Two open-source projects, at 17. Mimir Cloud lets peers submit WASM or JavaScript functions that worker nodes on the network discover, schedule, and run. MimirLLM does the same for language models — find the models peers are hosting and talk to them, running as a light client or a full node.

    Why it's here: Sharing compute and models across untrusted peers needs discovery, scheduling, and isolation with no server in the middle. That's the exact problem MoltMesh now solves for AI agents — I first worked it out as a teenager, years before agent meshes were a category. I wrote two articles on it.
